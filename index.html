01

GETTING STARTED

快速开始

将 UTF-8 编码的 .lua 文件放入脚本目录，在 Lua 页面扫描后点击加载。

脚本%LOCALAPPDATA%\LunarClient\lua\scripts
数据%LOCALAPPDATA%\LunarClient\lua\data
日志%LOCALAPPDATA%\LunarClient\lua\lua.log
hello_lunar.lua
local enabled = lunar.storage.get("enabled", true)

return {
  api = 1,
  requires = { "game.entities", "draw.rect" },
  name = "Hello Lunar",
  version = "1.0.0",

  on_draw = function(draw)
    if not enabled then return end
    for _, entity in ipairs(lunar.game.entities("survivor")) do
      if entity.has_box then
        draw.rect(entity.x, entity.y, entity.width, entity.height,
          { 0.81, 0.66, 0.70, 1.0 }, 1.5, 3.0)
      end
    end
  end
}
扫描与重载

重新扫描只同步文件列表并保留现有 VM；修改源码后使用脚本卡片上的“重载”。管理器加载状态只存在于当前会话。

02

MODULE CONTRACT

模块格式

脚本块返回模块表，api = 1 是唯一必需的版本字段。名称、回调和菜单页均按需声明。

字段类型说明
apiinteger当前固定为 1
requiresstring[]加载前检查的 API 点路径，最多 16 项
name / versionstring菜单显示信息，最多读取 128 字节
on_load / on_unloadfunction初始化与清理
on_tick / on_drawfunction逻辑与绘制回调
on_eventfunction当前接收 scene_changed
tabstable[]脚本菜单页，最多 16 项
R

依赖声明

路径不带 lunar. 前缀，例如 mad_eyes.place_wall。缺少依赖时加载在回调注册前结束。

T

菜单页

每项包含稳定的 id、显示 title 和 render(ui)。控件状态保存在脚本变量中。

04

DATA TYPES

通用数据结构

WorldPoint

{
  x = number,
  y = number,
  z = number,
  valid = boolean
}

读取世界坐标前检查 valid。

ScreenPoint

{
  x = number,
  y = number,
  visible = boolean
}

由 game.project 返回。

Color

{ r=1, g=.5, b=.7, a=1 }
{ 1, .5, .7, 1 }
0xFFFFFFFF -- ABGR

绘制分量限制到 0.0..1.0。

快照语义

宿主每帧复制数据到脚本私有 Lua 表。修改返回表只影响当前脚本变量。可选坐标使用 valid/visible；可选生命值通常以 -1 表示未知。

06

ERROR MODEL

错误与调试

加载期

依次检查文件、文本编译、返回表、API 版本、requires 和 on_load。错误文本保留在脚本卡片。

运行期

首次回调异常、指令超额或超时后停止脚本，在当前渲染/菜单阶段结束时关闭 VM。

日志

lunar.log.info/warn/error 与 print 写入 lua.log 和调试输出。

defensive.lua
local function valid_entity(entity)
  return entity
    and entity.root
    and entity.root.valid
    and not entity.is_dead
end

local player = lunar.game.local_player()
if valid_entity(player) then
  lunar.log.info("local uid: " .. player.uid)
end
